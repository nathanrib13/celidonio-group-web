# Celidonio Group

Site institucional do Grupo Celidonio. React + TypeScript + Vite, com Framer Motion para as interações.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Publicado automaticamente no GitHub Pages a cada push na branch `main`, via GitHub Actions (`.github/workflows/deploy.yml`).
